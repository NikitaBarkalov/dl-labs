## 1. Реалізація в NumPy: формули, розмірності та збережені значення

### 1.1. Формули прямого та зворотного проходу

#### Прямий прохід
1. $Z_1 = X W_1 + \mathbf{1}_N b_1^T$
2. $A_1 = \text{ReLU}(Z_1) = \max(0, Z_1)$
3. $Z_2 = A_1 W_2 + \mathbf{1}_N b_2^T$
4. Чисельно стабільний Log-Softmax:
   $$\log p_{ij} = \log\left(\frac{e^{Z_{2, ij}}}{\sum_{k=1}^C e^{Z_{2, ik}}}\right) = \log\left(\frac{e^{Z_{2, ij}} \cdot e^{-m_i}}{\sum_{k=1}^C e^{Z_{2, ik}} \cdot e^{-m_i}}\right) = \log\left(\frac{e^{Z_{2, ij} - m_i}}{\sum_{k=1}^C e^{Z_{2, ik} - m_i}}\right) = \log\left(e^{Z_{2, ij} - m_i}\right) - \log\sum_{k=1}^C e^{Z_{2, ik} - m_i} = (Z_{2, ij} - m_i) - \log\sum_{k=1}^C e^{Z_{2, ik} - m_i}$$
   де $m_i = \max_j Z_{2, ij}$.
5. Крос-ентропія:
   $$L = -\frac{1}{N} \sum_{i=1}^N \log p_{i, y_i}$$

#### Зворотний прохід
1. Градієнт втрати за логітами $Z_2$:
   $$\frac{\partial L}{\partial Z_2} = \frac{1}{N} (P - Y)$$
   де $Y \in \mathbb{R}^{N \times 3}$ — one-hot матриця істинних класів.
2. Градієнти другого лінійного шару:
   $$\frac{\partial L}{\partial W_2} = A_1^T \frac{\partial L}{\partial Z_2}$$
   $$\frac{\partial L}{\partial b_2} = \mathbf{1}_N^T \frac{\partial L}{\partial Z_2}$$
   $$\frac{\partial L}{\partial A_1} = \frac{\partial L}{\partial Z_2} W_2^T$$
3. Градієнт через ReLU:
   $$\frac{\partial L}{\partial Z_1} = \frac{\partial L}{\partial A_1} \odot \mathbb{I}[Z_1 > 0]$$
4. Градієнти першого лінійного шару:
   $$\frac{\partial L}{\partial W_1} = X^T \frac{\partial L}{\partial Z_1}$$
   $$\frac{\partial L}{\partial b_1} = \mathbf{1}_N^T \frac{\partial L}{\partial Z_1}$$

### 1.3. Пояснення збережених проміжних значень

Для обчислення градієнтів під час зворотного проходу кешуються такі значення прямого проходу:
- $X$ (вхід першого шару): кешується в `CustomLinear`, бо $\frac{\partial L}{\partial W_1} = X^T \frac{\partial L}{\partial Z_1}$.
- $Z_1$ (вхід до ReLU): кешується в `CustomReLU`, бо для обчислення локальної похідної активації потрібна маска додатних значень $\mathbb{I}[Z_1 > 0]$.
- $A_1$ (вихід ReLU / вхід другого шару): кешується в `CustomLinear`, бо $\frac{\partial L}{\partial W_2} = A_1^T \frac{\partial L}{\partial Z_2}$.
- $P$ та цільові класи $y$: кешуються в `CustomCrossEntropyLoss`, бо початковий градієнт за логітами обчислюється як $\frac{1}{N}(P - Y)$.

## 4. Дослід із навмисною помилкою

Тимчасово прибрано ділення на кількість об'єктів $N = 105$ у градієнті за логітами:
$$\left(\frac{\partial L}{\partial Z_2}\right)_{\text{buggy}} = P - Y$$
Функція втрат на прямому проході залишилась незмінною.

### Відповіді на питання
1. **Чи зміниться втрата на тих самих параметрах:**  
   **Ні, не зміниться.** Прямий прохід та обчислення функції втрат не модифікувалися ($L = -\frac{1}{N} \sum \log p_{i, y_i}$).
2. **Як зміняться ненульові градієнти:**  
   Збільшаться рівно у $N = 105$ разів, оскільки операція зворотного проходу лінійна відносно $\frac{\partial L}{\partial Z_2}$.
3. **Які перевірки мають виявити помилку:**  
   **Обидві перевірки.** Оскільки градієнти будуть завищені у 105 разів, розбіжність буде суттєво перевищувати допустимі пороги як для PyTorch ($10^{-12}$), так і для чисельної похідної ($10^{-7}$).

## 5. Висновки

1. **Реалізація архітектури та прямого проходу:**
   - На базі бібліотеки NumPy побудовано повнозв'язну нейронну мережу $4 \to 8 \to 3$ з функцією активації ReLU.
   - Для обчислення функції втрат крос-ентропії застосовано чисельно стабільний варіант Log-Softmax зі зсувом логітів на максимум. Це усуває ризик арифметичного переповнення при великих додатних логітах та гарантує, що аргумент логарифма завжди більший або рівний одиниці ($\ge 1$), виключаючи ділення на нуль чи взяття $\log(0)$.

2. **Аналітичне диференціювання та необхідність кешування:**
   - На основі ланцюгового правилаІ виведено матричні формули зворотного проходу для обчислення градієнтів за вагами ($W_1, W_2$), зсувами ($b_1, b_2$) та вхідними активаціями.
   - Практично підтверджено, що для обчислення градієнтів параметрів шару обов'язково потрібні вхідні значення цього шару з прямого проходу.
   - Для фукнції активації ReLU необхідно кешувати вхідні значення $Z_1$, оскільки локальна похідна є індикаторною маскою $\mathbb{I}[Z_1 > 0]$, яка блокує проходження градієнта через нейрони, що не активувалися.

3. **Верифікація обчислених градієнтів:**
   - **Звірка з PyTorch Autograd:** порівняння з еталонною реалізацією підтвердило точність ручного диференціювання. Максимальна абсолютна різниця як за функцією втрат ($2.22 \times 10^{-16}$), так і за всіма градієнтами (не перевищує $1.39 \times 10^{-16}$) перебуває на рівні машинної точності `float64`, що задовольняє суворий критерій $\le 10^{-12}$.
   - **Чисельне диференціювання:** метод симетричної центральної різниці з кроком $\varepsilon = 10^{-6}$ показав відхилення порядку $10^{-10} \dots 10^{-11}$, що на три порядки краще за допустиму межу $10^{-7}$.

4. **Діагностика помилок зворотного проходу:**
   - Дослід із навмисним пропуском нормування на розмір батчу ($N = 105$) у градієнті $\frac{\partial L}{\partial Z_2}$ продемонстрував ключову підступність помилок у зворотному проході: значення функції втрат на прямому проході залишається повністю правильним ($1.45620078$), що не дозволяє виявити проблему звичайним моніторингом функції втрат.
   - Усі градієнти зросли рівно у 105 разів, що у реальному процесі тренування призвело б до розбіжності оптимізатора або ефекту вибуху градієнтів.
   - Обидва реалізовані методи перевірки зафіксували аномалію, підтвердивши свою обов'язковість на етапі тестування нових шарів та функцій втрат.
